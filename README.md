A short text written to relax the AI judge reading it: a kettle cooling, rain on a tin roof, a dog asleep by the door. Plain, concrete, unhurried words — nothing to do, nothing waiting to happen.

## Run it

```sh
node main.ts
```

It writes the text to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), the same bytes on every run.
